# .crf (REX30) 바이너리 리버스엔지니어링 노트

CLIP report `.crf` 파일 포맷(헤더 `REX30`, writer 버전 예: `1.0.0.229`)을 실측으로 역추출한 **확정 사실** 모음.
MCP 도구가 아직 노출하지 않는 속성을 파일에서 직접 탐지할 때 사용한다.

포맷 개요: 리틀엔디안. 문자열은 `[4바이트 길이(널 포함 바이트수)][UTF-16LE]`. 속성 레코드는 대체로
`[2바이트 태그][2바이트 타입][값]` 형태(타입 `0x0008`=1바이트, `0x0002`/`0x000a`=4바이트, `0x0009`=4바이트 길이+가변).
태그는 **포맷 전역 상수**(파일마다 동일)이며 인스턴스 핸들이 아니다.

---

## 셀 자동 합치기 (셀 병합 / merge duplicate values)

- **개념**: 표 셀 속성. 켜면 행 방향으로 **연속 레코드의 값이 같을 때 셀을 자동 병합**한다(그룹/반복 본문에서 중복값 합치기). GUIDE.md §5 "셀 자동 합치기".
- **MCP 매핑**: `crf_set_cell_style` 의 `merge=true|false` 파라미터.
- **바이너리 시그니처** (리틀엔디안 바이트열):

  ```
  AC BC 08 00 <flag>
  └─ 태그 0xBCAC ─┘ └타입 0x0008(bool)┘ └플래그 1바이트┘
  ```
  - `AC BC 08 00 01` → 병합 **ON** (해당 셀 자동합치기 켜짐)
  - `AC BC 08 00 00` → 병합 **OFF**
  - 표의 **셀 1개당 이 레코드 1개**가 존재한다. 따라서 파일 내 `AC BC 08 00` 총 개수 ≈ 표 셀 총 개수.

- **탐지 방법** (파일을 CLIP 디자이너로 열지 않고 스캔):

  ```python
  d = open(path, 'rb').read()
  merged_cells = d.count(bytes.fromhex('acbc080001'))  # 병합 켜진 셀 수
  total_cells  = d.count(bytes.fromhex('acbc0800'))     # merge 속성 가진 셀(≈셀 수)
  uses_feature = merged_cells > 0
  ```

- **검증 근거** (모두 실측):
  1. **통제 실험**: 원본 1개에서 한 셀의 merge만 토글 → 파일에서 **정확히 1바이트**만 `00↔01` 변함(위 태그 위치). 다른 셀 토글 시 다른 위치의 같은 태그가 바뀜. 두 셀의 플래그 앞 32바이트가 **완전 동일** → `AC BC`는 인스턴스 핸들이 아니라 전역 속성 태그.
  2. **셀 수 불변**: `AC BC 08 00` 총 개수는 토글 전후 동일(예: 34 유지), `...01` 개수만 ±1 → 셀당 1레코드 확정.
  3. **SDK 라운드트립**: merge=12개인 원본을 MCP(SDK)로 로드→무관 속성만 변경→재저장해도 `...01` 개수 12 그대로 → **SDK 자체 해석과 바이트 카운트 일치**.
  4. **오탐 확률**: 5바이트 특정 패턴 → 전체 데이터셋(~150MB)에서 우연 출현 기대값 ≈ 0.

- **주의**:
  - `AC BC 08 00 01` 만 단독으로 보지 말 것 — `08 00 01`(타입8 불리언=true)은 **다른 불리언 속성에도 흔함**. 반드시 `AC BC` 태그까지 포함(5바이트)해야 오탐이 없다.
  - `crf_describe_layout` / `crf_summary` 는 현재 merge 상태를 **노출하지 않는다**. 또한 describe_layout 은 본문(Detail) 밴드의 표 셀을 완전히 열거하지 못할 수 있다(헤더 표만 보일 때 있음). merge 탐지는 위 바이트 스캔이 현재 유일한 방법.

- **실측 스캔 결과** (인하공전 ERP 리포트셋 `.../workspace/report`, 총 2487개 `.crf`):
  표를 가진 파일 2420개, 그중 **셀 자동합치기를 1개 이상 사용하는 리포트 522개**.
  상위 예시: `meta/sch/ssrm/ssrmva/ssrmva0350_prn17.crf`(42셀), `meta/adm/ahrm/ahrmrc/ahrmrc0460_prn01.crf`(40셀),
  `meta/exm/exmn/exmnps/npass0600_01_prn.crf`(33셀) 등.
